# Pager

## WTF?

This is a little play-area I've set up to show the easiest way (in my opinion) to provide paged interfaces using TypeScript - it probably won't be (entirely) suitable for production use, but it's kind of become a bit of an accidental passion-project.

## How do I run?

Put one foot in front of the other and fall onto it without falling over - do this as fast as you can whilst alternating which foot you use. This also provides the advantage of movement. Do not attempt this when you are sitting down.
